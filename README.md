### 2. Audience Status Lifecycle & Ad Campaign Integration
* **Audience Statuses:**
  1. *Ready:* Audience completely create ho chuki hai aur minimum required pixel matching size pura ho chuka hai[span_7](start_span)[span_7](end_span).
  2. *Populating / Ready:* Meta background mein historical data sync kar raha hai, ise campaign mein abhi bhi use kiya ja sakta hai[span_8](start_span)[span_8](end_span).
  3. *Not Available / Size Too Small:* Matched user count 100 se kam hai, ise use karne ke liye retention days badhane padte hain[span_9](start_span)[span_9](end_span).
* **How to Apply in Ad Campaign:** Campaign level par Ad Set level par jayein[span_10](start_span)[span_10](end_span). Custom Audiences section mein apni banayi hui audience (e.g., NITZ_Python_Web_Visitors_15D) select karein[span_11](start_span)[span_11](end_span).
* **Important Advantage:** Custom audience select karne ke baad age, gender, ya extra interest filters lagane ki zaroorat nahi hoti kyunki yeh log pehle se aapki website par aa chuke hote hain (100% genuine warm prospects)[span_12](start_span)[span_12](end_span).
